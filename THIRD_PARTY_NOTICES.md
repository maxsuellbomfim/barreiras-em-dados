# Avisos de terceiros

Nenhum código dos repositórios de referência foi incorporado nesta etapa.

As ideias avaliadas vieram de:

- **Honestidade Políticos Brasil**, conteúdo sob CC BY 4.0;
- **Polígrafo**, código sob MIT;
- **Transparência Política 2026**, `package.json` declara licença ISC, mas o
  arquivo ZIP analisado não contém texto de licença separado.

Qualquer incorporação futura deve identificar arquivos, versão/commit, licença,
atribuição e modificações. Dados e documentos coletados também devem registrar
os termos da fonte quando aplicável.
